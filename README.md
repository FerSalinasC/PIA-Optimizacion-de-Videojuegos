**Nombre del proyecto:** Alien Soccer

**Pitch:** Seremos un cadete espacial que ha llegado como último recurso para defender la última base de la tierra en la luna de una especie alienígena enemiga.

**Mecánicas:** El juego sera del tipo *tower defense* donde para defender nuestra base deberemos:

- Colocar torretas.
- Soportar oleadas de enemigos.

**Controles planeados:** Teclado

**Objetivo de rendimiento:** 60FPS

**Métricas que vamos a reportar:** FPS, load time, buid size, resolución de texturas.
